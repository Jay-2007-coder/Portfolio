## Tech Stack 🛠️

This portfolio is built using modern web technologies to ensure high performance and an engaging user experience, featuring 3D elements and smooth seamless animations:

- **Frontend Core:** React, TypeScript, Vite
- **Styling & Layout:** CSS, HTML5
- **Animations:** GSAP (GreenSock Animation Platform)
- **3D Graphics:** Three.js, React Three Fiber, WebGL, React Three Drei

## Getting Started 💻

To run this project locally, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Jay-2007-coder/Portfolio.git
   ```

2. **Navigate to the project directory:**
   ```bash
   cd Portfolio_Jay
   ```

3. **Install dependencies:**
   ```bash
   npm install
   ```

4. **Start the development server:**
   ```bash
   npm run dev
   ```

> **Note:** Important notice for deployment! I have modified the GSAP Club plugins to use trial plugins. With trial plugins, you cannot host your portfolio on a live server 🔴. For production deployment and acquiring proper Club plugins, please check out the GSAP installation guide here: [https://gsap.com/docs/v3/Installation/](https://gsap.com/docs/v3/Installation/)
